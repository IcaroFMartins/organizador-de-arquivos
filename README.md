# Organizador de Arquivos

Programa em Python que organiza arquivos de uma pasta em subpastas
por tipo de arquivo.

## Como executar

```bash
python3 main.py
```

Informe o caminho de uma pasta quando solicitado.

## Categorias

- Imagens
- Documentos
- Vídeos
- Áudios
- Compactados
- Códigos
- Outros

## O que aprendi

- Usar `pathlib` para trabalhar com caminhos
- Percorrer arquivos com `iterdir()`
- Criar pastas com `mkdir()`
- Mover arquivos com `shutil.move()`
- Organizar regras em dicionários
- Separar lógica de interface
